# Switzach

Run a separate iOS environment that is jailbroken.  
With actual real SpringBoard!

## Installation

1. [Install and setup Nyxian](/Nyxian/docs/installation.mdx)
    :::info

        Please use the ipa from our <a class="" href={ useDocusaurusContext().siteConfig.customFields.msgServerInvite }>Fluxer Server</a>
      
    :::

2. Download Procursus Jailed, if you haven't already
    > You can find the download in our <a class="" href={ useDocusaurusContext().siteConfig.customFields.msgServerInvite }>Fluxer Server</a>

3. Fully close Nyxian from the App Switcher

4. Reopen the app and immediatly hold/spam the bottom/right volume button
    > This should put you into Recovery, if not try again from step 3

5. Navigate to `Flash ROM` and select it

6. Select the zip file you downloaded in step 2

7. After the text stops scrolling press both volume up and down at the same time

8. Now just wait about 5 minutes and Switzach should be ready to use!
