# Procursus Jailed

Run a separate iOS environment that is jailbroken.  
With actual real SpringBoard!

## Installation

1. [Install and setup Nyxian](/Nyxian/docs/installation.mdx)

2. Download Procursus Jailed, if you haven't already
    > For now you can find the download in our <a class="" href={ useDocusaurusContext().siteConfig.customFields.discordInvite }>Discord</a>

3. Fully close Nyxian from the App Switcher

4. Reopen the app and immediatly spam the bottom/right volume button  
    > This should put you into Recovery, if not try again from step 3

5. Navigate to `Flash ROM` and select it
    > Navigate up and down with the volume buttons.  
    > Select by pressing both volume buttons at the same time.

6. Select the Procursus Jailed zip file you downloaded in step 2

7. After the text stops scrolling press both volume up and down at the same time

8. Now just wait about 5 minutes and Procursus Jailed should be ready to use!
