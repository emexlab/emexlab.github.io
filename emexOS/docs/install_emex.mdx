# How to install emexOS on your computer

when booting emexOS you will see this menu,
![bootup_emex_picture](/emexOS/img/bootup_emex.png)

use the arrow key down (↓) and select `install emexOS`
![install_emex_picture](/emexOS/img/install_emex.png)

this will install emexOS to your disk it should then look like this, 
![installed_emex_picture](/emexOS/img/installed_emex.png)


you can then reboot and emexOS should boot

:::note

it may not work on every hardware

:::
